Frontend Flow:
┌──────────────────────────────────────────┐
│ Terrestre.tsx (Page)                     │ ← Main page component
├──────────────────────────────────────────┤
│ useTerrialMap() Hook                     │ ← Manages state & lifecycle
│   ├─ Generate client_id                  │
│   ├─ Fetch graph via api.getGraph()      │
│   ├─ Fetch dinosaurs via api.getDinosaurs()
│   └─ Connect WebSocket via api.connectWebSocket()
├──────────────────────────────────────────┤
│ TerrestrialMap Component                 │ ← Renders SVG map
│   ├─ Calculate lat/lon to pixel coords   │
│   ├─ Draw edges (streets)                │
│   ├─ Draw nodes (intersections)          │
│   └─ Draw dinosaurs with status colors   │
└──────────────────────────────────────────┘


API Integration:
┌────────────────────────────────────────────┐
│ src/services/api.ts (Singleton)            │
├────────────────────────────────────────────┤
│ ✓ BackendAPI.getInstance()                │ ← Singleton pattern
│ ✓ getGraph()                               │ ← GET /graph
│ ✓ getDinosaurs()                           │ ← GET /dinosaurs
│ ✓ connectWebSocket(clientId, callback)     │ ← WS /ws/{client_id}
│ ✓ calculateRoute(clientId, from, to)       │ ← POST /route
│ ✓ deleteRoute(clientId)                    │ ← DELETE /route/{id}
└────────────────────────────────────────────┘


Data Flow:
Backend (http://localhost:8000)
        ↓
    GET /graph          → { nodes: {...}, edges: [...] }
        ↓
    GET /dinosaurs      → [ { id, specie, lat, lon, status, ... }, ... ]
        ↓
    WS /ws/{client_id}  → { type: "dinos_update", data: [...] } (every 3s)
        ↓
Frontend receives dinos_update
        ↓
TerrestrialMap re-renders with new positions

📊 DATA MODELS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dinosaur:
  - id: number
  - specie: string (Tyrannosaurus rex, Velociraptor, etc)
  - latitude: number
  - longitude: number
  - type: "herbivore" | "carnivore"
  - status: "calm" | "stressed" | "aggressive"
  - speed: number (m/s)
  - hunger: number (0-100)
  - stress: number (0-100)

GraphNode:
  - id: string (r0_c0, r0_c1, etc)
  - lat: number
  - lon: number
  - row: number
  - col: number

GraphEdge:
  - source: string (node id)
  - target: string (node id)
  - length: number (meters)
